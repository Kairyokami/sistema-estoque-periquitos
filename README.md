# sistema-estoque-periquitos
Sistema Desktop de Controle de Estoque para Mercadinho Periquitos.

## Tecnologias
- Java 17
- Maven
- Swing
- H2 Database
- FlatLaf

## Como executar
1. Instale Java 17+
2. Instale Maven
3. No terminal, execute:
   ```bash
   mvn clean package
   java -jar target/sistema-estoque-periquitos-1.0.0.jar
   ```

## Login padrão
- Usuário: `admin`
- Senha: `admin123`

## Funcionalidades desta versão inicial
- Login
- Dashboard
- Cadastro de produtos
- Cadastro de categorias
- Acesso a fornecedores e clientes
- Controle de estoque
- Relatórios básicos
